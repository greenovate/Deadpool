Recommended Improvements
  • Wire Arena Match Detection HIGH
    The Arena tab UI and data structure are ready, but no events are hooked to detect arena matches. Need to register for UPDATE_BATTLEFIELD_SCORE / ARENA_OPPONENT_UPDATE events and populate arenaLog entries with bracket, rating changes, teammate names, and opponent names.
  • Achievement Top 3 Display MEDIUM
    The achievement score sync (AS message) is broadcasting scores, but the Achievements tab doesn't yet show guild top 3 earners. The data is available via Deadpool:GetGuildAchScores() — needs a small UI addition at the top of the achievements panel.
  • Clean DemoData.lua Bounty References MEDIUM
    DemoData.lua still generates bounty demo data (bounties table, bountyKills in scoreboard, isBounty in kill log). Not causing errors since demo mode checks are safe, but creates inconsistent sample data when demo mode is enabled.
  • Rename BountyManager.lua MEDIUM
    File still called "BountyManager" but now only handles KOS management and point calculations. Consider renaming to KOSManager.lua or PointsManager.lua and updating the .toc file to match.
  • Version Bump to 1.7.0 LOW
    Major changes (bounty removal, point lock-in, arena tab, account-wide DB) warrant a new minor version. Currently still showing 1.6.2.
  • Scoreboard Column Shift LOW
    Removing the "Bounty" column from the scoreboard shifted columns. The Streak, Assists, and Ach Pts columns still reference old SetCol indices (7, 8 for data that was at 8, 9). Verify rendering is correct in-game.
  • Arena Rating History Graph IDEA
    Once arena tracking is wired, could show a simple rating-over-time trend using text-based sparklines or a frame-drawn chart on the dashboard.
  • Kill Heatmap by Zone IDEA
    Show which zones have the most PvP activity on the dashboard. Data is already tracked in achievements (zones_killed_in set). Could display top 5 zones with kill counts.
  • Nemesis System IDEA
    Auto-detect rivalry with specific enemy players (mutual kills). Show "Nemesis" badge on nearby widget and KOS list. Data already exists in enemySheet (timesKilledUs, timesWeKilledThem).
